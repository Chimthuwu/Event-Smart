SMARTEVENTS STUDIO
==================

1. Extract this ZIP to a normal folder.
2. Double-click Start-SmartEvents.bat.
3. The app opens at http://127.0.0.1:8000/SmartEvents-Studio.html.
4. Keep the small server window open while using the app.

Requires Python or Node.js and an internet connection (Three.js is loaded from jsDelivr).

INTRO
The intro uses your supplied logo URL and restores the composition from the HTML you sent:
radial dark background, rotating conic gradient, four sweeping lasers, four bouncing
speaker stacks/eight pulsing woofers, spinning + morphing logo, SmartEvents title,
Professional Production Studio subtitle and Launch Studio button. The hue slider is removed;
the hue flow is animated in the gradient itself.

CLEAR ALL
REMOVE ALL EQUIPMENT clears all placed equipment immediately. There is no browser confirm
popup to block the click. Use Undo in the top bar to restore the full previous layout.
